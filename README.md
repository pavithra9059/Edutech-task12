# Task 12: File Uploads & Cloud Storage Integration

## Objective

Implement image upload functionality using Multer and Cloudinary.

## Features

* Upload image files
* Handle multipart/form-data
* Store images on Cloudinary
* Return image URL
* File size validation
* REST API support

## Technologies Used

* Node.js
* Express.js
* Multer
* Cloudinary
* dotenv

## API Endpoint

POST /api/upload

### Request

multipart/form-data

Field Name: image

### Response

Returns uploaded image URL from Cloudinary.

## Outcome

Successfully implemented media asset handling using Multer and Cloudinary cloud storage.
